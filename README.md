# Alien DNA Mixer Minecraft Plugin

Alien DNA Mixer is a Minecraft plugin for a mob DNA collection and mixing adventure. Defeat supported creatures to collect DNA samples, combine samples from three different species, and brew a serum that grants temporary abilities.

## Install

1. Build the project with Java 21 and Maven by running `mvn package`.
2. Copy `target/plugin.jar` into your Paper server's `plugins` folder.
3. Restart the server.

## Use

1. Run `/adventure start` to receive the mysterious capsule and Alex's field guide.
2. Right-click the capsule to reveal the Alien Watch.
3. Defeat zombies, spiders, skeletons, slimes, creepers, endermen, bees, or blazes to collect their DNA samples.
4. Run `/dna mix <sample1> <sample2> <sample3>` with three different supported species. The samples are consumed when mixing succeeds.
5. Run `/alienbrew` while carrying both the Alien Watch and Complete Alien DNA. This consumes them and gives you a Friendly Alien Serum.
6. Right-click the serum for Speed, Jump Boost, and Night Vision for one minute. Run `/alex` for in-game guidance.
